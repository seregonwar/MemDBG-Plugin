# MemDBG Plugin Repository

repository link:

`https://github.com/seregonwar/MemDBG-Plugin`

Fork the repository, edit `manifest.json`, add your Lua or Python scripts under
`plugins/`, add optional catalog images under `assets/`, then add your fork URL
in MemDBG's **Plugins** page. A GitHub repo URL, a raw `manifest.json` URL, or a
local folder/file path are all accepted.

Use `summary` for the short text shown in the plugin list and `description`
for the complete details text. The UI keeps cards compact and exposes the full
description through the details panel expand control.

Each plugin receives one argument: a JSON context file generated by MemDBG. The
context includes console endpoint, selected process, dump/trainer paths, map
count, scan hit count, and trainer entry count.

Python plugins can include `sdk/memdbg.py` as `memdbg.py` and use:

```python
from memdbg import MemDBG
api = MemDBG.from_context()
print(api.process_list())
```

The same SDK includes `run_mcp_stdio()` for building MCP stdio bridge plugins
that expose MemDBG process and memory APIs to external clients.
